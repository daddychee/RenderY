# NHẬT KÝ MÁY EDITOR — kênh bàn giao tri thức về máy gốc

> Máy editor GHI (Claude Code tự làm theo CLAUDE.md §7); user đọc trên máy gốc.
> Mỗi bug fix / luật mới / sự kiện đáng nhớ = 1 entry, **MỚI NHẤT TRÊN CÙNG**.
> Kèm theo mỗi entry: mirror memory file vào `memory_moi\` + cập nhật `padoma_editor.bundle`.

```

- **Vấn đề:** <hiện tượng / đang chạy lệnh gì>
- **Root cause:** <nguyên nhân thật>
- **Fix:** <đổi gì, file nào>
- **Test:** <pytest x/x + cổng mắt/tai nếu có>
- **Memory:** <tên file .md đã mirror vào memory_moi\, hoặc "không">
```
