# Phiếu hiểu khán giả (hợp đồng khán giả)

Bản cho editor nằm ở trang web **Hướng dẫn**, tab `phieu-hieu-khan-gia` (nguồn: `docs/huong-dan/phieu-hieu-khan-gia.md` của repo chính). Sửa phiếu thì sửa ở đó.

Editor gửi phiếu về thì chủ dự án nhờ Claude chuyển thành mục 0 "Hợp đồng khán giả" của `kien-thuc/khung/<niche>.md`, thay các dòng "(tạm, chờ editor)".
