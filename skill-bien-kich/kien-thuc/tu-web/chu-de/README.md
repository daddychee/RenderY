# Nguyên tắc theo chủ đề

Mỗi chủ đề (niche) một file, **chỉ khi có điều riêng** ngoài file chung và file loại. Tên file theo niche trong DB, không dấu, gạch nối: `travel.md`, `dong-vat.md`, `deepsea.md`, `space.md`, `nghi-huu.md`, `phim-tai-lieu.md`, `nature-sound.md`, `dien-anh.md`.

Cùng khung 6 mục như file loại. Mục 6 phải ghi rõ rút từ đợt thử nào hoặc tài liệu nào.

Hiện có: `travel.md`, `dong-vat.md`, `deepsea.md` (điền từ kinh nghiệm 12 đến 17/09), `tien-su-khung-long.md` (lập 18/09 tối cho Spec 22, toàn giả thuyết), `hanh-dong.md` (26/09, cảnh đánh nhau, từ đợt thử hành động 1). Các chủ đề khác tạo khi có kiến thức.
